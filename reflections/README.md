## 如何积累

- 原理问题、设计质疑和有价值的认识变化整理成笔记；普通操作与重复问题不单独收录。
- 使用 [个人思考模板](_template.md)。同主题补充新反例、条件和认识变化，不按每轮聊天新建文章。
- 忠实保留本人原问题与已表达的观点。助手归纳的结论标注“助手整理”；没有复述或实践证据时，不写成已经掌握。
- 后续遇到相关练习，引用笔记中的问题进行复述或迁移验证，把实际回答和结果补回原笔记。

## 状态

| 状态 | 需要的证据 |
| --- | --- |
| 待复习 | 已形成笔记；助手归纳的部分尚未经本人复述 |
| 已能复述 | 本人在不看笔记时解释机制和至少一个反例 |
| 有实现支撑 | 在理解基础上，能说明自己实现或复现了什么、结果证明什么 |

有新证据时更新一次。助手写的代码或做的实验不能代替本人的理解证据。

## 一次简短复习

1. 读笔记顶部的速记，合上正文，用自己的话解释原问题。
2. 回答自测题，并说明答案在什么条件下会变化。
3. 把答不清的地方和修正后的理解补入原笔记。
