这里的公司环境、服务、指标和事件全部为学习而虚构，不描述任何真实生产系统。`2026-11-06T06:00:00Z` 是固定实验快照时间，不代表查询时的实时状态。

- [服务快照](service-snapshot.json)：未来查询工具返回的数据来源。
- [起始用例](../evals/starter-cases.json)：人工审查与后续自动评测的输入。

开始时先实现固定快照查询。后续加入明确的场景选择器，模拟超时、工具错误、旧文档和并发请求。任何实际业务接入都应在独立任务中确定范围。
