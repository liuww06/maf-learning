# AI Agent 工程面试训练

回答采用“定义 → 执行机制 → 适用条件与代价 → 项目证据 → 局限”结构。先独立回答，再用实验纠正。没有实测的数据不写进简历，也不把练习系统描述为真实生产经历。

| 主题 | 主问题 | 深入追问 | 应准备的证据 |
| --- | --- | --- | --- |
| 基本模型 | 一次 LLM 调用、Agent、工作流分别是什么？ | 什么时候一个普通函数就足够？ | 主线应用的执行图 |
| 工具调用 | 模型如何调用一个 C# 函数？ | schema 错误、未知工具、调用 ID 缺失怎样处理？ | 一次完整消息序列和失败测试 |
| 运行时 | 自己写 Agent loop 最少需要什么？ | 模型一直调用工具如何终止？ | 自研循环、预算和取消测试 |
| 上下文 | 如何控制长会话成本？ | 摘要丢失重要事实怎么办？ | 上下文策略对照结果 |
| 状态 | session、历史、记忆、业务状态有什么区别？ | 多实例并发更新如何处理？ | 存储设计和冲突处理实验 |
| RAG | 为什么加了向量数据库仍然答错？ | 如何区分召回失败和生成失败？ | 标注集、Recall@k、错误案例 |
| 输出验证 | JSON 输出成功意味着任务成功吗？ | 如何验证引用与业务约束？ | 输出校验和证据验证逻辑 |
| 编排 | 为什么采用单 Agent 或工作流？ | 多 Agent 的收益如何证明？ | 相同任务的质量、延迟和成本对照 |
| 恢复 | 工具已成功，但保存 checkpoint 前崩溃怎么办？ | 为什么重试可能产生重复副作用？ | 幂等键、唯一约束和故障注入 |
| 人工审批 | 审批到底授权了什么？ | 审批后工具参数发生变化怎么办？ | 操作内容绑定和失效测试 |
| 隔离 | 如何避免跨用户读取会话？ | 文档提示注入能否绕过权限？ | 身份边界、过滤与越权测试 |
| 可观测性 | 如何定位一次 Agent 任务失败？ | 哪些内容应记录，哪些需要脱敏？ | trace 与复盘记录 |
| 评测 | 如何判断更换模型或提示后更好了？ | 小样本、裁判偏差、保留集污染如何处理？ | 版本化评测和失败分布 |
| 框架设计 | 为什么这些接口需要抽象？ | provider 差异无法统一时怎么办？ | 两个业务复用、适配器与 ADR |
| 协议 | MCP、普通函数工具和 A2A 的边界是什么？ | 协议接入是否等于安全、可靠？ | 接入实验与能力限制 |
| .NET 工程 | CancellationToken、DI 生命周期和流式响应如何结合？ | 客户端断开后任务还在运行吗？ | API 层取消和资源释放测试 |

## 三种练习

- 每课：用两分钟解释本课一个机制，并回答一个反例。
- 每阶段：用十分钟讲解系统设计，解释三个取舍和一个失败场景。
- 结课：用三十分钟完成设计追问、现场增加工具、定位故障、说明框架能力边界。

熟练度按证据记录：0 未学习，1 能解释，2 能独立实现，3 能排障并比较方案。由助手写出标准答案，不会自动提高个人熟练度。
