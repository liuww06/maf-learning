## 用户提供的配置

- 协议：OpenAI Responses。
- Base URL：`http://127.0.0.1:3425/v1`。
- 未指定模型；助手从实时模型列表选用 `codex/gpt-6.1-sol` 作为可配置默认值。

## 本轮实现

新增 [FirstAgent](../apps/FirstAgent/README.md) 控制台项目，固定 MAF 包版本为 `1.27.0`，生成依赖锁文件。提供普通与流式两种模式、可配置模型与 endpoint、60 秒默认取消期限、Ctrl+C 取消、耗时和用量显示。SDK 自动重试设为 0；使用 `store=false`。

上游源码没有修改。当前应用依赖与本地上游 HEAD 并非同一版本：应用的 `Microsoft.Extensions.AI.OpenAI` 为 `10.10.1`，源码 HEAD 的集中声明为 `10.11.0`。对照实现时以应用包或 `dotnet-1.27.0` 标签为准。

## 实际验证

| 检查 | 观察结果 |
| --- | --- |
| GET `/v1/models` | HTTP 200；本次读取无需认证，列表包含上述模型和 Responses 路径 |
| NuGet 还原 | 成功，生成 `packages.lock.json` |
| 编译 | 最终 0 警告、0 错误 |
| 流式调用 | 退出码 0，收到文字与用量，完成原因 `stop` |
| 普通调用 | 退出码 0，收到文字与用量；本次 MAF 响应对象的完成原因未提供 |
| 非法模式 | 调用前拒绝，退出码 2 |
| 非法 base URL | 调用前拒绝，退出码 2 |
| 超时值为 0 | 调用前拒绝，退出码 2 |

两次生成调用均通过已启动的本地 Magpie 网关，使用应用的默认配置。本次环境无需另外配置网关密钥即可完成调用，代码中的非空凭据为占位值。

| 模式 | 首 Agent 更新 | 首文字 | 总耗时 | 输入 token | 输出 token | 总 token |
| --- | --- | --- | --- | --- | --- | --- |
| stream | 5474 ms | 5497 ms | 8511 ms | 4209 | 52 | 4261 |
| once | 不适用 | 未单独测量 | 6800 ms | 4209 | 47 | 4256 |

流式共观察到 58 条 Agent 更新。token 数据为响应路径上报值，尚未拆解网关或上游是否加入其他上下文，不能仅根据控制台提示长度推算。两次调用合计上报 8517 token，没有计算货币费用。

以上各一次调用仅用于连通性和基本响应验证，不能用来比较两种模式的性能。普通模式缺少完成原因的具体归属层尚未定位，保留为观测差异。未验证工具调用、结构化输出、多轮会话、实际超时和中途取消。

## 运行命令

```bash
dotnet apps/FirstAgent/bin/Debug/net10.0/FirstAgent.dll stream
dotnet apps/FirstAgent/bin/Debug/net10.0/FirstAgent.dll once
```

本轮构建使用以下环境隔离缓存；临时日志位于 `/tmp/maf-first-agent-restore.log` 和 `/tmp/maf-first-agent-build.log`：

```bash
env DOTNET_CLI_HOME=/tmp/maf-dotnet-home NUGET_PACKAGES=/tmp/maf-nuget NUGET_HTTP_CACHE_PATH=/tmp/maf-nuget-http DOTNET_CLI_TELEMETRY_OPTOUT=1 dotnet restore apps/FirstAgent/FirstAgent.csproj --source https://api.nuget.org/v3/index.json --tl:off
env DOTNET_CLI_HOME=/tmp/maf-dotnet-home NUGET_PACKAGES=/tmp/maf-nuget NUGET_HTTP_CACHE_PATH=/tmp/maf-nuget-http DOTNET_CLI_TELEMETRY_OPTOUT=1 dotnet build apps/FirstAgent/FirstAgent.csproj --no-restore --tl:off
```

## 本轮遇到的问题

- 沙箱禁止本地网络连接，读取网关、还原包和运行示例分别按环境规则取得执行许可后完成。属于执行环境限制。
- 初次编译遇到 `OPENAI001`，实际解析的 OpenAI 2.14.0 对相关 Responses API 带实验性标记。仅在使用位置局部抑制后重新编译通过。
